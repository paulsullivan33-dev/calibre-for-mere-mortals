# The Neighbours

Calibre is not the only way books get
managed, and for some readers it isn't
the right one. The honest comparison:

| Neighbour | What it is | What it trades |
|---|---|---|
| **The Kindle shop** | Buy on Amazon, books appear on the device | Ultimate ease; the library is Amazon's, exports are limited, and the books are DRM-locked to the ecosystem |
| **Kobo shop** | The same shape, from Rakuten | Slightly more open (EPUB at its core); still a shop first and a manager second |
| **Apple Books / Google Play Books** | The platform shops on phones | Fine readers, no real library management, no conversion, tied to one account |
| **calibre-web** | A web front-end that reads a calibre library | A prettier, multi-user web shelf for a library calibre maintains; not a manager itself — it sits on top of the same `metadata.db` |
| **Kavita / Komga** | Self-hosted library servers, comics-first | Lovely for manga and comics with per-page reading; book metadata and conversion are not their game |
| **Ubooquity** | A simple self-hosted book and comic server | Lightweight serving, no catalogue editing or conversion to speak of |
| **Thorium Reader** | A free desktop/mobile reading app (EDRLab) | An excellent armchair; shelves are the device's problem, it manages nothing |
| **Zotero** | Reference manager for research | Citations, PDFs and bibliographies done properly; fiction readers will find it joyless, which is mutual |

## How to choose

- **You buy everything from one shop
  and read on its devices.** Stay in the
  shop. Calibre adds power you don't
  need, and the shop's DRM wall
  (chapter 13) limits what it can do
  with those books anyway.
- **Your books come from everywhere and
  go to several devices.** That is
  calibre's exact home ground — one
  catalogue, every format, your folder.
- **The household wants a pretty web
  shelf, phones first.** Calibre as the
  back office with calibre-web, or the
  built-in content server (chapter 9),
  as the front door.
- **The collection is comics.** Trial
  Kavita or Komga seriously; calibre
  catalogues comics but reading them
  page by page is the neighbours'
  craft.
- **The collection is a thesis.**
  Zotero for the papers and citations;
  calibre, if at all, for the novels.

Nothing here is exclusive: libraries
commonly run calibre for management and
one neighbour for reading, which is the
shape chapter 8 describes.
